# Output tokens

[Tokens](https://fderuiter.github.io/agy-skills/dictionary/token) the [model](https://fderuiter.github.io/agy-skills/dictionary/model) generates back. Billed at a higher rate than [input tokens](https://fderuiter.github.io/agy-skills/dictionary/input-tokens), commonly around five times the rate, since they cost more compute to produce.

Everything the model writes counts: the prose you read, the code it emits, [tool calls](https://fderuiter.github.io/agy-skills/dictionary/tool-call), and any extended thinking the model does before answering. That last one surprises people, reasoning tokens are billed as output even when the [harness](https://fderuiter.github.io/agy-skills/dictionary/harness) often doesn't show them to you, and turning up [effort](https://fderuiter.github.io/agy-skills/dictionary/effort) spends more of them.

Output tokens also set the pace of a [session](https://fderuiter.github.io/agy-skills/dictionary/session). The model reads input quickly but generates output one token at a time, so when a [turn](https://fderuiter.github.io/agy-skills/dictionary/turn) feels slow, it's almost always the output being written, not the input being read. A long wait usually means a long answer is coming.

_Usage:_

"The refactor session is burning through credit even though the inputs are small."

"Agent's rewriting whole files instead of patching. Output tokens cost roughly five times the input rate, get it emitting edits and the bill drops."
